安装 PeerTTY

Debian 和 Ubuntu

Debian 12 或 Ubuntu 22.04 及更新版本支持以下安装方式，适用于 amd64 和 arm64。

curl -fsSLo peertty.sources https://chiway-luo.github.io/PeerTTY/peertty.sources &&
sudo install -m 0644 peertty.sources /etc/apt/sources.list.d/peertty.sources &&
sudo apt update &&
sudo apt install peertty

已添加软件源的设备先用 peertty revoke 结束活动授权，再运行 sudo apt update && sudo apt install --only-upgrade peertty。

Fedora 和 RHEL

下载 x86_64 RPM 或 aarch64 RPM 及同版发行公钥。首次安装时，先核对指纹并验签。

Windows 和 macOS

  • Windows 安装包适用于 x64 和 ARM64。
  • macOS 通用安装包适用于 Apple 芯片和 Intel。

安装后运行 peertty --version 核对版本，再运行 peertty 打开菜单。v0.6.4 安装包、校验和及更新说明
